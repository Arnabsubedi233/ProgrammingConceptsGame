# Law And Disorder

Welcome to **Law And Disorder**, a thrilling game where you navigate through levels, shoot cops to escape into your hideout. This README will guide you through the installation process and help you get started.

---

## Installation

### Prerequisites
- Make sure you have **Python** and **Pygame** installed on your computer.

#### Installing Python
1. Download Python from the official website: [Python Downloads](https://www.python.org/downloads/).
2. Follow the installation instructions for your operating system.

#### Installing Pygame
Once Python is installed, you can install Pygame using `pip`. Open your terminal or command prompt and run:

```bash
pip install pygame
```

---

## Cloning the Repository

Clone the git repository to your local machine using the following command:

```bash
git clone https://github.com/Arnabsubedi233/ProgrammingConceptsGame.git
```
Then, navigate to the project directory:

```bash
cd ProgrammingConceptsGame
```

---

## Running the Game

To run the game, execute the following command in your terminal or command prompt:

```bash
python game.py
```

---

## Game Controls

- **A**: Move left  
- **D**: Move right  
- **W**: Jump  
- **Q**: Throw grenade  
- **Space**: Shoot  

---

Enjoy playing **Law And Disorder**!
